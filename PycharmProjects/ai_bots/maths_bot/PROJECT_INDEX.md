## 🚀 Common Tasks

### Task: Start the Bot
**Windows**: Double-click `START_CHATBOT.bat`
**Manual**: Run `streamlit run app.py`
See **QUICK_REFERENCE.md**

### Task: Install Dependencies
```bash
pip install -r requirements.txt
```
See **SETUP_GUIDE.md** → Step 5

### Task: Solve a Math Problem
1. Start the bot
2. Select category and difficulty in sidebar
3. Ask your question
4. Review the solution
See **README.md** → How to Use

### Task: Enable Verification
1. Check "Verify answer with alternate method" in sidebar
2. Ask a question
3. Bot will show verification steps
See **LAUNCH_CHECKLIST.md** → Feature Test

### Task: Get Practice Problems
1. Check "Show practice problems" in sidebar
2. Ask a question
3. Bot provides 2-3 similar problems
See **README.md** → Smart Features

### Task: Change Learning Style
1. Select different style in "Learning Style" dropdown
2. Ask a question
3. Response adjusts to selected style
See **README.md** → Learning Styles

### Task: Fix Ollama Connection Error
See **LAUNCH_CHECKLIST.md** → Troubleshooting During Launch
Or **QUICK_REFERENCE.md** → Troubleshooting

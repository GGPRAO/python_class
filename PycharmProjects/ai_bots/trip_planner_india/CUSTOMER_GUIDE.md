# India Trip Planner Chatbot - Customer Interaction Guide

## 🎯 For Customers: How to Get the Best Trip Plans

This guide explains how to interact with the chatbot to get the best personalized trip recommendations.

---

## 📋 Before You Start

### Step 1: Choose Your Preferences (Sidebar)

Before asking any questions, set up your preferences in the left sidebar:

```
1️⃣  Trip Type
    ├─ Family Trip (kids, activities suited for families)
    ├─ Solo Travel (budget, safety, social activities)
    ├─ Couple Trip (romantic locations, special experiences)
    ├─ Friends Group (adventure, group activities)
    ├─ Adventure Group (trekking, sports, exploration)
    └─ Senior Citizens (comfortable pace, accessible)

2️⃣  Transportation Mode (Choose all that apply)
    ├─ ✈️  Flight (for long distances, quick travel)
    ├─ 🚂 Train (scenic, budget-friendly for medium distances)
    ├─ 🚌 Bus (very budget-friendly, but slower)
    └─ 🚗 Car/Road Trip (flexible, scenic routes, best for groups)

3️⃣  Budget Level
    ├─ Budget Friendly (hostels, street food, public transport)
    ├─ Affordable (3-star hotels, local restaurants)
    ├─ Mid-Range (4-star hotels, good dining)
    ├─ Premium (5-star hotels, fine dining)
    └─ Luxury (ultra-premium, all amenities)

4️⃣  Number of Days (1-30)
    └─ How many days for your trip?

5️⃣  Region Interest
    ├─ North India (Taj Mahal, deserts, mountains)
    ├─ South India (beaches, backwaters, temples)
    ├─ East India (tea gardens, wildlife, mountains)
    ├─ West India (forts, beaches, wine)
    ├─ Northeast India (tribal culture, wildlife)
    └─ All India (multi-state tour)

6️⃣  Number of People
    └─ How many people are traveling?

7️⃣  Total Budget (₹)
    └─ Your total budget for the entire trip

8️⃣  Weather Consideration
    └─ Enable to get seasonal recommendations
```

## 🆘 Getting Help During Planning

### If Responses Are Generic
```
Add more details:
❌ "Plan a trip to Kerala"
✅ "Plan a 4-day couple trip to Kerala in December with ₹60,000 budget, 
   focusing on backwaters and beaches, prefer train travel"
```

### If Prices Seem Outdated
```
Mention current date/inflation:
❌ "How much does it cost?"
✅ "What are current 2026 prices for hotels and flights?"
```

### If You Need Specific Info
```
Ask directly:
❌ "What about food?"
✅ "What are famous Rajasthani dishes and where to eat them safely?"
```

## 💡 Pro Tips for Best Results

### 1. Set Preferences First ⚙️
Always set sidebar preferences before asking - the bot customizes answers based on these.

### 2. Be Specific 📝
Include: Location, dates/season, number of people, budget, trip type

### 3. Ask Follow-ups 🔄
First: "What are main attractions in Kerala?"
Second: "How much would it cost for families?"
Third: "Best transportation options?"

### 4. Mention Constraints 🚧
- Time limitations
- Physical limitations (mobility, altitude sensitivity)
- Dietary restrictions
- Any specific interests or fears

### 5. Use Quick Buttons 🔘
Click the pre-made quick questions for common queries

### 6. Check Weather First 🌤️
Enable weather consideration for seasonal accuracy

### 7. Compare Options 🔄
Ask: "Flight vs train vs bus for this route?" to get comparison

### 8. Verify Details ✓
Cross-check prices and bookings on official websites

## 📞 Tips for Troubleshooting

### Chatbot Not Responding
```
1. Check Ollama is running: Run "ollama run qwen2:1.5b" in PowerShell
2. Refresh browser: Press Ctrl+R
3. Check internet connection
4. Wait for response (first response takes longer)
```

### Responses Not Personalized
```
1. Set sidebar preferences first
2. Be more specific in your query
3. Include all relevant details (people, budget, dates)
4. Try rephrasing the question
```

### Getting Repetitive Answers
```
1. Ask more specific follow-up questions
2. Request different format (tables, lists, etc.)
3. Ask for alternatives or comparisons
4. Mention what you liked/disliked about previous answer
```

# ⚡ Quick Reference Card

## 🚀 THREE WAYS TO RUN (Pick ONE)

### ✅ **Recommended** - No PyArrow Issues
```
Double-click: run_simple_ui.bat
OR
python simple_http_ui.py
```
→ Opens: http://localhost:5000

### Flask Version
```
Double-click: run_chatgpt_ui.bat
OR
python flask_chatgpt_ui.py
```

### Streamlit Version
```
streamlit run chatgpt_ui.py
```
⚠️ May have PyArrow DLL errors

---

## 🔍 BEFORE YOU START

**Must Do:**
1. ✅ Install Ollama: https://ollama.ai
2. ✅ Open terminal and run: `ollama serve qwen2:1.5b`
3. ✅ Keep that terminal open!

---

## 🎯 STEP-BY-STEP

### Windows (Easiest)
1. Go to `ai_bot` folder
2. **Double-click** `run_simple_ui.bat`
3. Wait for "Server running at http://localhost:5000"
4. Open browser → http://localhost:5000
5. Start typing!

### Mac/Linux Terminal
1. Navigate to `ai_bot` folder
2. Run: `python simple_http_ui.py`
3. Open: http://localhost:5000
4. Chat away!

---

## 🐛 FIXES FOR COMMON ERRORS

| Error | Fix |
|-------|-----|
| **DLL load failed** | Use `simple_http_ui.py` ✅ |
| **No module 'ollama'** | `pip install ollama` |
| **Connection refused** | Start Ollama: `ollama serve` |
| **Port 5000 in use** | Change PORT = 5001 in the file |
| **Model not found** | `ollama pull qwen2:1.5b` |

## 🎨 CUSTOMIZE COLORS

Edit `chatgpt_ui.html`, find:
```css
#667eea 0%, #764ba2
```

Try:
- **Blue**: `#00d4ff 0%, #0099ff`
- **Green**: `#00d4aa 0%, #00aa55`

## 🆘 EMERGENCY FIX

If something breaks:

```bash
# Kill any hung processes
taskkill /F /IM python.exe

# Reinstall everything
pip uninstall ollama -y
pip install ollama

# Restart Ollama
ollama serve qwen2:1.5b

# Try again
python simple_http_ui.py
```

## 🆘 Troubleshooting Guide

### Issue: Installation fails
→ Check [README.md - Prerequisites](README.md#prerequisites)
→ Check [QUICKSTART.md - Verify Setup](QUICKSTART.md#-verify-setup)

### Issue: Gmail authentication fails
→ Check [QUICKSTART.md - Configure Gmail](QUICKSTART.md#-configure-gmail-2-min)
→ Check [README.md - Troubleshooting](README.md#-troubleshooting)

### Issue: Ollama connection error
→ Check [README.md - Troubleshooting](README.md#-troubleshooting)
→ Run: `ollama serve` in a separate terminal

### Issue: No emails found
→ Check [README.md - Troubleshooting](README.md#-troubleshooting)
→ Verify Naukri emails exist in your inbox

### Issue: App crashes
→ Check [QUICKSTART.md - Troubleshooting](QUICKSTART.md#-troubleshooting-issues)
→ Review error message in terminal
→ Check [NAVIGATION_GUIDE.md - Debug Checklist](NAVIGATION_GUIDE.md#-debug-checklist)

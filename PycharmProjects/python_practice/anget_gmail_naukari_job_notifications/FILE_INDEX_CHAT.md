## 🔧 Troubleshooting

### Problem: Chat bot won't start
**Solution:**
```bash
python -m pip install flask flask-cors
python lightweight_chat_bot.py
```

### Problem: Port 5000 in use
**Solution:**
Edit `lightweight_chat_bot.py`, change:
```python
port = 5000  # to port = 5001 (or any free port)
```

### Problem: Gmail not working
**Solution:**
```bash
python -c "from gmail import *; print('OK')"
```

### Problem: Browser won't open
**Solution:**
Manually open: `http://localhost:5000`

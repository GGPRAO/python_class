🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

  Issue: "Chat bot won't start"
    → Run: python -m pip install flask flask-cors
    → Then: python lightweight_chat_bot.py

  Issue: "Port 5000 in use"
    → Edit lightweight_chat_bot.py, change port = 5000 to 5001
    → Then: python lightweight_chat_bot.py

  Issue: "Gmail not working"
    → Check Gmail module: python -c "from gmail import *"
    → Verify credentials in gmail/gmail_config.py

  Issue: "Browser won't open"
    → Manually open: http://localhost:5000
    → Or: http://127.0.0.1:5000

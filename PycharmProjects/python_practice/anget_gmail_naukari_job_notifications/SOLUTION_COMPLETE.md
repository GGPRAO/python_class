## 🎓 Technical Implementation

### Stack
- **Frontend**: HTML5 + CSS3 + Vanilla JavaScript
- **Backend**: Flask (Python web framework)
- **Search**: Gmail API (existing module)
- **Storage**: Session-based (in-memory)
- **Deployment**: Localhost (http://127.0.0.1:5000)

### Why Flask?
- ✅ Lightweight (no bloat)
- ✅ Pure Python
- ✅ No external DLL dependencies
- ✅ Works with security policies
- ✅ Easy to customize
- ✅ No complex setup required

### Why Not Streamlit?
- ❌ Depends on PyArrow
- ❌ PyArrow has DLL blocked
- ❌ Can't run on restricted systems
- ❌ No simple PyArrow fix exists
- ❌ Flask is lighter weight

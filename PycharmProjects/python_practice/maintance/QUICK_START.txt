🎓 HOW TO USE - EXAMPLE WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Launch app → http://127.0.0.1:5000/

  2. View dashboard:
     - See all 483 houses
     - See summary cards with counts

  3. Find house H-001:
     - Click payment dropdown → Select "Paid" → Click [Set]
     - Click availability dropdown → Select "Available" → Click [Set]

  4. Add maintenance for February 2026:
     - Click month picker
     - Select "2026-02"
     - Click "+ Month"
     - Row highlights green (✅ Paid)

  5. Export data:
     - Click "Export CSV"
     - File houses.csv downloads
     - Open in Excel/Sheets

  6. Done! You've managed your first house 🎉

💡 WHAT IS THIS SYSTEM?

A web app that manages 483 houses for Prajay Water Front Phase 2:

✅ Payment Status: Track if each house rent is paid or not
✅ Availability: Track if house is available, rented, or occupied
✅ Month-wise Maintenance: Track maintenance payment per month
✅ Sync Feature: Payment and maintenance for current month auto-sync

Example:
  • Mark house as "PAID" → Maintenance for this month auto-becomes "PAID"
  • Mark house as "NOT PAID" → Maintenance auto-becomes "NOT PAID"
  • Works both ways!


═══════════════════════════════════════════════════════════════════

🎮 HOW TO USE:

1. View Dashboard:
   - See total 483 houses
   - See summary cards (Paid, Not Paid, Available, Rented, Occupied, Maintenance Paid)

2. Change Payment Status:
   - Find house H-001 in the table
   - Click "Payment" dropdown
   - Select ✅ PAID or ❌ NOT PAID
   - Dropdown auto-submits
   - Watch Maintenance for current month auto-update! 🔄

3. Change Availability:
   - Click "Availability" dropdown
   - Select AVAILABLE, RENTED, or OCCUPIED
   - Auto-submits

4. Add Maintenance for Any Month:
   - Click month picker (📅)
   - Select any month (e.g., 2026-03)
   - Click "+ Month"
   - If current month → Payment auto-syncs ✅

5. Export Data:
   - Click "📥 Export CSV"
   - File downloads as houses.csv
   - Open in Excel, Google Sheets, etc.


═══════════════════════════════════════════════════════════════════

🔄 WHAT IS SYNC?

Current Month (2026-02):
  When you change PAYMENT → MAINTENANCE auto-updates
  When you change MAINTENANCE → PAYMENT auto-updates
  They stay in sync! 🔗

Future Months (2026-03, etc.):
  You can add maintenance for any month
  It doesn't affect payment status
  They're independent

🆘 IF SOMETHING GOES WRONG:

Port 5000 Already in Use:
  Edit app.py, last line, change:
    app.run(debug=True)
  To:
    app.run(debug=True, port=5001)
  Then open: http://127.0.0.1:5001/

Missing Dependencies:
  cd C:\Users\USER\PycharmProjects\python_practice\maintance
  python -m pip install -r requirements.txt

Database Issues:
  Delete maintenance.db
  Run: python init_db.py
  Run: python migrate_db.py
